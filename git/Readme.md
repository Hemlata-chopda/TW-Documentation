# Git

## Introduction
Git is a distributed version control system used to track changes in files and manage source code. It helps developers maintain different versions of a project and work efficiently.

## Topics Covered
- Introduction to Version Control Systems
- Types of Version Control Systems
- Introduction to Git and its features
- Installing and configuring Git
- Git repository and its structure
- Working directory, staging area, and repository
- Basic Git workflow
- Initializing a repository using `git init`
- Tracking files using `git add`
- Saving changes using `git commit`
- Checking repository status using `git status`
- Viewing commit history using `git log`
- Comparing changes using `git diff`
- Managing files and changes
- Branching and merging
- Resolving merge conflicts
- Undoing changes and restoring previous versions
- Git best practices

## Important Git Commands

| Command | Purpose |
|---|---|
| `git init` | Initialize a Git repository |
| `git config` | Configure Git settings |
| `git status` | Check the current repository status |
| `git add` | Add changes to the staging area |
| `git commit` | Save changes in the repository |
| `git log` | View commit history |
| `git diff` | Compare changes |
| `git branch` | Manage branches |
| `git checkout` | Switch branches or restore files |
| `git merge` | Merge branches |

This section covers the fundamentals of Git, from repository creation and file tracking to commits, branching, and merging. It provides practical knowledge of version control for software development.
